# context/: how five people and their AI agents worked on one repo in 48 hours

Every person drove several Claude Code sessions at once. Each session read these files before working, so they stayed in sync. They are kept as a record of the process; the polished overview is the [README](../README.md) at the top of the repo.

| File | What it is |
|---|---|
| `MASTER_PLAN.md` | The plan written on day 1: verdict, architecture, frozen interfaces, work packages, timeline, risks (some later superseded) |
| `DECISIONS.md` | Every scope or architecture decision with time, who, what and why, including reversals |
| `LOG.md` | Running log: what each person finished, what was next, blockers for others |
| `TASKS.md` | Who owned what |
| `BRINGUP_FINDINGS.md`, `MOTION_TEST.md` | Getting the real robot connected and moving for the first time |
| `EXERCISE_MAP.md` | Which app exercises the robot can perform |
| `PITCH.md`, `PITCH_SCRIPT_v2.md` | Pitch format, scripts and shoot plan |
| `KICKOFF.md`, `PROJECT.md`, `EVENT.md`, `NFC.md` | Day-1 packages, event information, NFC setup |

Numbers in the planning files marked [U] or [ASSUMPTION] were working notes, not claims; the checked figures are in the pitch deck.
